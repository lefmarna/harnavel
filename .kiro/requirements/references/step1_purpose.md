# Step 1: Purpose

**Goal**: Clarify core problem and feature value

**Completion**: User can articulate problem and goals clearly

**Output**: `1_purpose.md`

## Pre-Step: Code Investigation

Before asking questions:
1. Identify mentioned screens/features/components in codebase
2. Understand current implementation, UI structure, data models
3. Check existing tests/test plans if available
4. Ask only essential questions based on findings

## Key Questions

- What specific problem are we solving?
- Who experiences this problem and how?
- What is the ideal outcome (goal)?
- Why is this needed now?
