# Step 3: Scope

**Goal**: Define minimum viable implementation

**Completion**: Features categorized as MVP / Nice-to-Have / Future

**Output**: `3_scope.md`

## Pre-Step: Code Investigation

Before defining scope:
1. Check implementation complexity (simple change vs. major refactor)
2. Identify dependent features/components
3. Understand technical constraints and existing patterns
4. Propose MVP/Nice-to-Have/Future based on difficulty
