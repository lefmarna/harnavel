# Laravel Docker Template

Laravel + MariaDB + Docker development environment template.

## Tech Stack

- **Backend**: Laravel 12, Fortify, Pest v4
- **Frontend**: React 19, Inertia v2, Tailwind v4, Radix UI
- **Infra**: Docker, Nginx, MariaDB, Wayfinder
