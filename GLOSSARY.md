# Domain Glossary

Ubiquitous domain language of this project. Read before planning, designing, or refactoring; update
when domain language changes.

Rules:

- Domain language only — no implementation details, file paths, or class names.
- Current state only — rewrite superseded meanings instead of appending history.
- Entries may use Japanese; keep this header as is.
- App-owned (seeded by the template, never merged back). Split into `GLOSSARY-MAP.md` plus
  per-context files only when multiple bounded contexts emerge.

Entry format:

```markdown
## <Term>

<One-paragraph definition. Add synonyms or non-meanings only when confusion is a real risk.>
```
